# 拼写听写练习

一个无需安装、可离线打开的英语逐词听写网页原型。

## 首次安装

双击 `setup.bat`。它会在项目目录中安装本地英文语音识别组件，不会修改系统 Python。

## 启动

以后每次双击 `start.bat`，应用会等待本地识别服务就绪，再自动打开 `http://127.0.0.1:8767`。服务会在后台运行，启动窗口关闭后也不会中断。请不要直接双击 `index.html`，否则自动识别服务无法使用。

不再使用应用时可以双击 `stop.bat` 停止后台识别服务；平时保持运行也不会主动处理或上传任何文件。

- 点击“播放句子”或“重听”朗读英文。
- 逐词输入，按空格切换到下一个单词。
- `Tab` 临时显示答案。
- `~` 重听当前句子。
- 点击“检查答案”获得逐词反馈。

## 导入真人音频

1. 点击页面上方的“导入真人音频”。
2. 选择本机的 MP3、M4A、WAV 或 OGG 文件。
3. 选择识别精度并点击“自动识别并生成时间稿”。
4. 检查识别出的英文，修正人名、数字和专业词。
5. 如果以后还会使用该音频，点击“保存此时间稿”。
6. 点击“生成听写题”，应用会从第一段真人音频开始练习。

保存时间稿后，下次选择文件名、大小和修改时间均相同的音频，页面会显示“发现这个文件以前保存的时间稿”。点击“导入已保存时间稿”即可跳过语音识别。时间稿最多保存 30 份，只保存在当前浏览器的本地存储中；清除浏览器网站数据后记录也会被删除。

识别精度：

- 快速（`tiny.en`）：模型较小，速度最快，适合先试用。
- 均衡（`base.en`）：默认选项，准确率和速度较平衡。
- 较准确（`small.en`）：更慢、占用更多空间，适合口音或新闻音频。

生成范围：

- 全部脚本：保留识别到的全部有效片段。
- 精选 10/20/30 条：先识别完整音频，再优先保留长度适中、词汇较丰富的句子，并过滤过短、填充词过多或内容高度重复的片段。
- 如果符合条件的句子少于目标数量，将按实际数量生成，不用简单句凑数。

识别产生的底层片段会按停顿、句末标点和句子长度重新合并，避免把解码器的中间切点误当成完整例句。播放每道真人音频题时，句首会额外保留约 0.35 秒，句尾保留约 0.25 秒，减少第一个音节或结尾被截断的情况。

每个模型第一次使用时会下载到项目的 `.models` 文件夹，以后可离线使用。识别完全在本机运行，音频不会上传到外部服务。

如果已经有时间稿，也可以跳过自动识别，直接粘贴以下格式。

推荐的一行一题格式：

```text
00:00.000 --> 00:05.200 | Bank of America announced a new initiative. | 美国银行宣布了一项新计划。
00:05.200 --> 00:10.800 | The program will support energy infrastructure. | 该计划将支持能源基础设施。
```

最后的中文提示可以省略，也可以直接粘贴标准 SRT 字幕，例如：

```text
1
00:00:00,000 --> 00:00:05,200
Bank of America announced a new initiative.

2
00:00:05,200 --> 00:00:10,800
The program will support energy infrastructure.
```

音频只在本机的浏览器与识别服务之间传递，不会上传到云端。刷新或关闭页面后，浏览器会撤销对音频的临时访问权限，需要重新选择文件。

## 收藏例句

听写时点击播放按钮旁边的“收藏例句”，当前英文、中文提示、来源音频和时间段会写入项目根目录的 `例句.md`。相同英文只保存一次，再次收藏会提示已经存在。

练习句维护在 `app.js` 顶部的 `lessons` 数组中；每项包含中文 `zh` 和英文 `en`。
